## Не требует переноса

iOS-специфичные исправления, у Android этих проблем нет:

- Остановка системного NFC-листа перед закрытием, кнопка «Сканировать» для перезапуска в провижининге
  (CoreNFC-лист модальный; в Android — reader mode).
- Приглушение чужого аудио только на время звука скана (`AVAudioSession`).
- Конфетти при завершении взятия — в Android уже есть (`ScanScreen.ConfettiOverlay`).
- Полоса «NFC недоступен» вместо постоянной «NFC активен» — в Android уже есть `NfcState.Disabled`.
