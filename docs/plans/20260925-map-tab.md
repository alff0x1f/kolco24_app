# Вкладка «Карта»: трек + взятые КП на оффлайн-подложке (MBTiles, MapLibre)

## Overview

Новая вкладка «Карта» между «Легендой» и «Командой»: живой GPS-трек команды и взятые КП
поверх растровой подложки. Подложка — один MBTiles-файл на гонку (`races[].map_url`),
скачивается явной кнопкой до старта, дальше карта работает полностью оффлайн. Без файла —
онлайн-подложка OSM с тем же треком и КП.

Паритет с iOS: спецификация `~/src/kolco24_ios/kolco24/docs/plans/completed/20260717-map-tab.md`,
`docs/IOS-PARITY.md` п.1.

Ключевые решения (брейншторм 2026-09-25 + plan-review):
- **Движок — MapLibre Native Android.** osmdroid заархивирован (2024-11), свой рендер — перебор.
  Оффлайн и онлайн — один механизм raster-источника: `"url": "mbtiles:///<path>"` (TileJSON строит
  сам MapLibre из `metadata`, y-flip тоже его) или `"tiles": [OSM-шаблон]`. Своего ридера тайлов нет.
  Работоспособность `mbtiles://` проверяется spike-задачей **до** остальной работы (Task 1).
- **Онлайн-подложка — OSM** (`https://tile.openstreetmap.org/{z}/{x}/{y}.png`), без ключей и биллинга.
- **Координаты КП с сервера не приходят** — пин по GPS-фиксу отметки (`MarkEntity.locLat/locLon`).
  Отметки без фикса на карте не показываются — осознанно.
- **Файл = флаг «скачано»**, без prefs. Скачивание: `.part` → проверка SQLite → атомарный `renameTo`.
  Файлы в `noBackupFilesDir/maps/` — вне Auto Backup (квота 25 МБ).
- **Доступность: сначала файл, потом `mapUrl`** (отличие от iOS) — локальный режим перезаписывает
  каталог гонок LAN-данными, где `map_url` может не быть; скачанная карта не должна пропадать.
- **`MapView` живёт только на осевшей вкладке** (`pagerState.settledPage == 2`) — не создаётся
  off-screen (`beyondViewportPageCount = 1`) и при анимации `switchToTab(0↔3)` через страницу 2.

## Technical Details

**MBTiles**: `tiles(zoom_level, tile_column, tile_row, tile_data)` + `metadata(name, value)`
(`bounds` = «W,S,E,N», `minzoom`, `maxzoom`, `format`). Строки TMS — флип делает MapLibre-источник
`mbtiles://`. Metadata читаем сами — только для камеры и ограничения зума.

**`MbtilesMetadata`**: `data class MbtilesMetadata(bounds: Bounds?, minZoom: Int?, maxZoom: Int?)`,
`Bounds(west, south, east, north)`. `parseMbtilesMetadata(Map<String, String>)` — never throws:
`bounds` строго 4 числа через запятую (`trim` + `toDoubleOrNull`, dot-decimal), иначе `null`;
зумы — `toIntOrNull`.

**Хранение**: `context.noBackupFilesDir/maps/<raceId>.mbtiles` (Auto Backup не трогает — квота 25 МБ
иначе сорвала бы бэкап `kolco24.db`). Скачивание пишет в `<raceId>.mbtiles.part`; успех →
валидация → `renameTo` поверх (атомарная замена на Linux; `delete`+`rename` — только фолбэк, если
rename не удался). Ошибка/отмена → `.part` удалён. На старте (`Kolco24App`, рядом с
`sweepOrphanPhotoDirs`) — удалить все `*.part` (процесс убит посреди скачивания).
Кэш MapLibre (`filesDir/mbgl-offline.db`, подтверждено в spike) исключить в обоих backup-XML.
`AppContainer.clearDatabase()` карты **не** трогает — это не БД; фиксируется в DATA-NOTES.

**`MapDownloader`** (`download(url, raceId, onProgress)`): отдельный `OkHttpClient`
(без `AppSignatureInterceptor`/`ServerTimeInterceptor`), `readTimeout` ~60 с. Если `contentLength`
известен и больше `usableSpace` каталога → сразу `IOException("Недостаточно места")`. Поток
буфером 64 КБ, `onProgress(bytesRead, contentLength)` (`≤ 0` → неопределённый). HTTP ≠ 2xx →
`IOException`. Отмена — `ensureActive()` в цикле + `call.cancel()`. Перед commit —
`validate(partFile)`-лямбда (прод: `SQLiteDatabase.openDatabase(READONLY)` + `SELECT 1 FROM tiles LIMIT 1`
есть строка; иначе `IOException("Файл карты повреждён")`) — отсекает HTML captive-portal/прокси.

**`MapRepository(storage, download: suspend (url, raceId, onProgress) -> Unit, scope)`**:
- `state: StateFlow<MapDownloadState>` — `Idle` / `Downloading(raceId, progress: Float?)` /
  `Failed(raceId, message)`; `consumeFailure()` → `Idle`.
- `downloaded: StateFlow<Set<Int>>` — засеян с диска при создании, обновляется после успешного
  `download` и `delete`. Единственный источник «файл есть» для UI — ручных пересчётов нет.
- `download(raceId, url)` — no-op, если уже `Downloading` (любой гонки); корутина на
  `applicationScope`, `Job` хранится для `cancel()`.
- `delete(raceId)` — no-op во время скачивания этой гонки.
- `metadata(raceId)`, `path(raceId)`, `size(raceId)`.

**`MapAvailability`** (чистая `mapAvailability(raceId, mapUrl, downloaded, downloadState)`):
1. `raceId in downloaded` → `Ready`
2. `Downloading(raceId == текущая)` → `Downloading(progress)`
3. `mapUrl == null` → `NoMapForRace`
4. `Downloading(другая гонка)` → `BusyOtherRace` (CTA неактивна, «Идёт скачивание карты другой гонки»)
5. иначе → `NotDownloaded`

**Данные для рендера** (`MapLogic`, чистое):
- трек — уже посчитанный `trackUsable` из `MainActivity` → `trackGeoJson(points)` (только `lat/lon`).
- `mapPins(marks, checkpointCosts)` — только `complete && locLat != null && locLon != null`,
  по одному пину на `checkpointId` (самая ранняя по `trustedTakenAt ?: takenAt`);
  `MapPin(checkpointId, number = checkpointNumber, cost = checkpointCosts[id] ?: mark.cost,
  timeMs = trustedTakenAt ?: takenAt, lat, lon)`.
- `pinsGeoJson(pins)` → `Point`-features с properties `id`, `icon = "kp-<number>"`.
  Сборка через `kotlinx.serialization.json` (`buildJsonObject`) — без MapLibre-типов.
- `pinCaption(pin, timeZone: TimeZone)` → «КП 32 · 4 балла · 14:07» (`pluralRu`,
  `SimpleDateFormat("HH:mm", Locale.US)` c переданной TZ — тест фиксирует TZ).
- `formatMapSize(bytes)` → «34 МБ» / «820 КБ».

**Рендер (`TrackMapView`)**:
- `MapLibre.getInstance(context)` + `HttpRequestUtil.setOkHttpClient(...)` — лениво, один раз, перед
  первым `MapView` (не на каждом холодном старте). Интерсептор ставит User-Agent через
  `header("User-Agent", "Kolco24-Android/<versionName>")` (замена, не `addHeader`) — требование OSM.
- Композится только при `pagerState.settledPage == 2`; иначе `MapScreen` показывает пустой фон.
  `AndroidView(factory = { MapView(it).apply { onCreate(null) } })`; lifecycle через
  `LocalLifecycleOwner` + `LifecycleEventObserver` (`onStart/onResume/onPause/onStop`), `onLowMemory`
  через `ComponentCallbacks2`; в `onDispose` — `onPause/onStop` по текущему состоянию, затем `onDestroy`.
  Если в spike SurfaceView глючит — `MapLibreMapOptions.textureMode(true)`.
- Стиль из JSON-строки в коде:
  - оффлайн: `{"type":"raster","url":"mbtiles:///<abs path>","tileSize":256}`;
  - онлайн: `{"type":"raster","tiles":["https://tile.openstreetmap.org/{z}/{x}/{y}.png"],"tileSize":256,
    "maxzoom":19,"attribution":"© OpenStreetMap contributors"}`.
  Смена `Ready ↔ online` → `setStyle` заново, после чего **заново**: `addImage` всех иконок, источники
  трека/пинов, активация `LocationComponent`, первичная камера.
- Трек: `GeoJsonSource("track")` + `LineLayer` (`OrangeCta`, 3 dp); обновление — `setGeoJson`.
- КП: `GeoJsonSource("pins")` + `SymbolLayer` (`iconImage = get("icon")`, `iconAllowOverlap = true`).
  Иконки — `Bitmap` из `PinBitmaps` (красный кружок + белый номер `RobotoMono`, кэш по номеру),
  `style.addImage` для новых номеров. Glyphs не используем (грузятся из сети).
- Тап: `addOnMapClickListener` → `queryRenderedFeatures(point, "pins-layer")` → `onPinClick(id)`;
  карточка с `pinCaption` рисуется в Compose (`MapScreen`), тап мимо — скрыть.
- «Я»: `LocationComponent` только при выданном `ACCESS_FINE/COARSE_LOCATION`. Это второй
  GPS-клиент рядом с `TrackRecordingService` — только пока вкладка открыта (`settledPage`-гейт).
- Камера (при каждой установке стиля): metadata `bounds` → `setLatLngBoundsForCameraTarget` +
  `setMin/MaxZoomPreference` + кадр по bounds; без файла — fit по треку+пинам (padding 48 dp),
  если пусто — последняя известная позиция `LocationComponent`, иначе дефолтный кадр.

**Итоги spike (Task 1)** — эмулятор API 36 (arm64), `org.maplibre.gl:android-sdk:13.6.1`:
- Сборка на AGP 9.2 / minSdk 24 без доп. настроек; `libmaplibre.so` грузится.
- Рабочий стиль (проверен как есть):
  ```json
  {"version":8,
   "sources":{"base":{"type":"raster","url":"mbtiles:///data/user/0/ru.kolco24.kolco24/no_backup/maps/<raceId>.mbtiles","tileSize":256}},
   "layers":[{"id":"base","type":"raster","source":"base"}]}
  ```
  т.е. `"url": "mbtiles://" + file.absolutePath` (путь абсолютный → три слэша). `"tiles"` для
  `mbtiles://` не нужен — TileJSON MapLibre строит сам из `metadata`. `tileSize: 256` задавать явно
  (дефолт raster-источника — 512).
- y-flip верный: оффлайн-рендер из TMS-строк совпадает пиксель в пиксель с онлайн-OSM на той же
  камере. В авиарежиме (`airplane-mode enable` + wifi/data off) оффлайн-подложка рендерится полностью.
- OSM-стиль (`"tiles":[...]`, см. выше) рендерится, HTTP 200. Glyphs/спрайты не нужны.
- Кэш MapLibre: `context.filesDir/mbgl-offline.db` (создаётся при первом `MapView`, в т.ч. в чисто
  оффлайн-стиле; растёт от онлайн-тайлов OSM). Исключать в backup-XML как
  `<exclude domain="file" path="mbgl-offline.db"/>`.
- SurfaceView в `HorizontalPager`: при перелистывании едет вместе со страницей, без артефактов и
  z-order-проблем → `textureMode` **не нужен**. Нюанс: `MapView` съедает горизонтальный drag (панорама
  карты), поэтому свайпом с вкладки «Карта» уйти нельзя — только через `NavigationBar`. Принимается
  (как в любом картографическом приложении); в проде `MapView` к тому же живёт только на
  `settledPage == 2`, так что при свайпе *на* вкладку видно пустой фон, карта появляется после остановки.

**UI состояний (`MapScreen`)**: нет команды → пустое состояние «Выберите команду» с кнопкой.
Поверх карты: `NoMapForRace` — плашка «Оффлайн-карта для этой гонки недоступна»;
`NotDownloaded` — карточка «Скачать карту гонки» внизу; `BusyOtherRace` — та же карточка,
кнопка неактивна, подпись «Идёт скачивание карты другой гонки»; `Downloading` — карточка с
`LinearProgressIndicator` (неопределённый при `progress == null`), процентом и отменой; `Ready` —
ничего. Онлайн-режим (не `Ready`) — строка «© OpenStreetMap contributors» в углу (видимая
атрибуция, не только (i)-кнопка). `Failed` → snackbar «Не удалось скачать карту: …».

**Иконка вкладки**: «Карта» — `Icons.Filled/Outlined.Place`; «Легенда» остаётся на `Map`
(менять иконку существующей вкладки — вне скоупа).

**Серверный контракт** (вне репо): `GET /app/races/` отдаёт опциональный `map_url` — прямой URL
статики `.mbtiles`, без HMAC. **HTTPS обязателен** (или LAN `http://192.168.1.5/...`).

## Post-Completion

**Сервер** (вне репо, `~/src/kolco24`):
- поле `map_url` в `GET /app/races/` (`null` = карты нет), HTTPS;
- генерация `<race>.mbtiles` из XYZ-тайлов (bbox района, z8–15, `metadata.bounds/minzoom/maxzoom/format`),
  раздача статикой без подписи.

**Ручная проверка на устройстве:**
- скачать карту по Wi-Fi → авиарежим → вкладка «Карта»: подложка, трек, КП, камера ограничена районом;
- обрыв сети посреди скачивания → snackbar, повтор с нуля;
- captive-portal Wi-Fi (HTML вместо файла) → snackbar, карта не «скачана»;
- гонка без `map_url` → OSM онлайн + плашка; строка атрибуции видна;
- удаление карты в настройках → вкладка в `NotDownloaded`;
- переключение вкладок во время скачивания — скачивание продолжается; при сворачивании приложения
  надолго ОС может убить процесс (нет foreground-сервиса) — принято, повтор с нуля;
- размер APK до/после (MapLibre, нативные либы по ABI); расход батареи с открытой вкладкой
  (второй GPS-клиент `LocationComponent`).
